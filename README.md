# Лис и Марта — сайт-концепт

## Запуск

Требуется Node.js 18+. Выполните:

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173). Для production-сборки: `npm run build`, для просмотра сборки: `npm run preview`.

## Аудит источника (20 октября 2026)

Сайт https://plutos.tagancy.ru/ содержит сведения о подборе автомобилей в Крыму («Подбор Авто»), не о мастерской «Лис и Марта». Ни одна услуга, цена, контакт, отзыв или фотография оттуда не перенесены. Подтверждённые данные проекта: пользовательский логотип, название и тексты первого экрана, заданные в техническом задании. Формулировки остальных разделов — структура прототипа, не обещания компании.

## Контент и изображения

- `src/content.js` — централизованные названия, описания, программы, цены, возраст, длительность, FAQ, этапы, галерея, контакты.
- `public/logo-original.jpg` — исходное изображение логотипа без изменения цветов и пропорций. Изображение включает белые поля и рамку оригинального файла; при наличии прозрачного оригинала рекомендуется заменить его с сохранением композиции.
- Фотографии услуг и галереи **не использованы**: декоративные эмодзи и CSS-заливки — временные иллюстративные заглушки. Лицензии на внешние фото не требуются, так как внешние фото не добавлялись.
- Шрифты Comfortaa, Nunito Sans и Caveat загружаются из Google Fonts (перед публикацией проверьте условия OFL и при необходимости разместите локально).
- Названия «Детский праздник», «Анимационные программы», «Шоу и развлечения» — навигационные категории-заглушки, не подтверждённые предложения.
- Блок преимуществ, отзывы, контакты, юридическая информация и политика — заглушки.

## Страницы

- `/` — главная со всеми запрошенными разделами;
- `/service/prazdnik`, `/service/animaciya`, `/service/show` — шаблоны услуг;
- `/program/programma-1` (и 2, 3) — шаблоны программ;
- `/contacts` — контакты и заявка;
- `/privacy` — заглушка политики.

## Функциональность

**Работает:** адаптивное меню, навигация, маршруты, FAQ, выбор этапов, проверка формы, анимации с поддержкой reduced motion, кнопки и клавиатурный фокус.

**Прототип:** галерея открывает модальное окно с заглушкой (Escape, клик вне окна и кнопка закрытия); реальные фотографии появятся после получения прав. Цены, программы, преимущества, отзывы — placeholders.

**Не подключено:** backend, CRM, отправка писем, мессенджеры, аналитика, публикация юридических документов. Форма **не отправляет** и не сохраняет данные; после валидации честно сообщает об отсутствии подключения. Состояния загрузки/успеха/серверной ошибки должны быть реализованы при интеграции реального API.
