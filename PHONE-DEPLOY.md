# Как опубликовать сайт с телефона

Проект подготовлен для Vercel (Vite + React).

1. Распакуйте ZIP в приложении «Файлы» на телефоне.
2. В браузере откройте github.com, войдите и создайте новый публичный или приватный репозиторий (без README).
3. В репозитории выберите Add file → Upload files и загрузите файлы и папки проекта, сохранив структуру. На телефоне загрузка папок может быть неудобной: при необходимости используйте браузер в режиме «Версия для ПК» или компьютер. ZIP целиком в репозиторий загружать недостаточно.
4. Откройте vercel.com/new, авторизуйтесь через GitHub, импортируйте репозиторий.
5. Framework Preset: Vite. Нажмите Deploy. После завершения откройте ссылку *.vercel.app.

Важно: форма заявки в этом прототипе не отправляет сообщения. До публикации для клиентов замените заглушки цен, контактов, отзывов и политики.
